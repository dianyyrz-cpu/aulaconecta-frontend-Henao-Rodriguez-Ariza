# AulaConecta Front-End

## Descripción

AulaConecta es un proyecto orientado al desarrollo del front-end de una plataforma web que permitirá consultar cursos disponibles, registrar personas interesadas y administrar contenidos de manera organizada. Este repositorio constituye la base de trabajo colaborativo para el diseño y planificación de la aplicación antes del inicio del desarrollo con React.

---

# Problema que resuelve

Actualmente los archivos del proyecto se intercambian mediante carpetas y aplicaciones de mensajería, lo que provoca pérdida de versiones, sobreescritura de cambios y dificultades para identificar quién realizó cada modificación.

El uso de Git y GitHub permitirá mantener un historial de cambios, facilitar el trabajo colaborativo y garantizar que las modificaciones sean revisadas antes de incorporarse a la versión principal.

---

# Objetivo del Front-End

Diseñar y preparar la estructura inicial del proyecto web AulaConecta, definiendo la organización del repositorio y la documentación necesaria para iniciar posteriormente el desarrollo utilizando tecnologías modernas de Front-End.

---

# Alcance Inicial

Durante esta fase únicamente se preparará la documentación y la organización del proyecto.

En futuras etapas se desarrollarán los siguientes módulos:

- Página principal
- Catálogo de cursos
- Registro de personas interesadas
- Panel de administración

# Acuerdo de trabajo

El equipo establece las siguientes reglas de colaboración:

- La rama principal será **main**.
- Ningún integrante modificará directamente la rama principal.
- Todos los cambios deberán realizarse desde una rama independiente.
- Cada commit deberá tener un mensaje claro y descriptivo.
- Antes de integrar cambios en main será obligatorio realizar una revisión mediante Pull Request.
- Las observaciones realizadas durante la revisión deberán corregirse antes de la fusión.
- Cada mensaje de commit deberá describir claramente el cambio realizado para facilitar el seguimiento del historial del proyecto.
---

# Criterios de calidad

Antes de fusionar cualquier contribución deberá verificarse que:

- La documentación esté completa.
- No existan errores ortográficos.
- Los mensajes de commit describan claramente el cambio realizado.
- No se publiquen archivos sensibles ni información privada.
- La estructura del proyecto permanezca organizada y fácil de comprender.
